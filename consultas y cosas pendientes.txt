a tener en cuenta luego:


Many to many hashtags

Esto:
Post.belongsToMany(Hashtag, { through: 'PostHashtags',foreignKey:'idPost'})
Hashtag.belongsToMany(Post, { through: 'PostHashtags' ,foreignKey:'idHashtag'})


está medio invertido.

Debería ser:

Post.belongsToMany(Hashtag, {
    through: 'PostHashtags',
    foreignKey: 'idPost',
    otherKey: 'idHashtag'
})

Hashtag.belongsToMany(Post, {
    through: 'PostHashtags',
    foreignKey: 'idHashtag',
    otherKey: 'idPost'
})


///////////////////////////////////////

Collection ↔ Post

También podés definir explícitamente:

Collection.belongsToMany(Post,{
    through:'SavedPosts',
    foreignKey:'idCollection',
    otherKey:'idPost'
})

Post.belongsToMany(Collection,{
    through:'SavedPosts',
    foreignKey:'idPost',
    otherKey:'idCollection'
})


La idea clave es:

belongsTo -> la FK vive en ESTA tabla
hasMany   -> la FK vive en la OTRA tabla

Ejemplo:

User 1:N Post

Entonces:

Post guarda idUser
